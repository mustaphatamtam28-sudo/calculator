Quadratic Equation Calculator

Solve ax² + bx + c = 0.

Enter coefficients to see the roots.

How it works

This calculator solves quadratic equations using the standard quadratic formula. It is useful for algebra, physics, engineering, and any problem where a second-degree equation needs to be solved. The result may include two real roots, one repeated root, or complex roots depending on the discriminant.

Enter values for a, b, and c, then press the button to calculate the solutions. If the equation has real answers, the tool will show both roots clearly. If the equation has no real roots, it will explain that the result is complex.
