About This Tool

Matrices are rectangular arrays of numbers used in algebra, geometry, physics, computer graphics, and many engineering fields. They can be added, subtracted, and multiplied when dimensions allow it. This calculator helps you perform those basic matrix operations quickly by entering values in a simple text format.

To enter a matrix, type each row on a new line and separate numbers with spaces. For example, a 2×2 matrix can be written as two lines with two numbers on each line. The tool checks whether the matrices have compatible dimensions before calculating the result. If the sizes do not match, it will display a helpful message instead of producing an invalid answer.

Matrix math is an important part of many higher-level math topics, including linear algebra and systems of equations.
