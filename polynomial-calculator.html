Polynomial Calculator

Evaluate a polynomial for a given value of x.

Result:
Enter coefficients and x to evaluate the polynomial.

How to Use

Enter coefficients in descending order of powers. For example, 2, -3, 5 means \(2x^2 - 3x + 5\).

  • The first number is the coefficient of the highest power
  • The last number is the constant term
  • Useful for algebra and function evaluation
Tip: Keep coefficients separated by commas.
