Vector Calculator

Calculate vector addition and subtraction for 2D vectors.

Enter vector components to see the result.

How it works

Vectors are quantities that have both size and direction. In 2D form, they are often written as coordinates such as (x, y). This calculator helps users add and subtract two vectors quickly, which is useful in geometry, physics, navigation, and basic engineering problems.

Enter the x and y components of both vectors, then press calculate. The tool will return the sum and difference in coordinate form so the result is easy to read and use. This makes it helpful for homework, class exercises, and quick checks.
