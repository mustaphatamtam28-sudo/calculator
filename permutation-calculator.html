Permutation Calculator

Calculate nPr values for combinations where order matters.

Enter values for n and r to see the result.

How it works

Permutations are used when selecting items and the order matters. The formula is nPr = n! / (n - r)!. This calculator is useful in mathematics, probability, statistics, arrangements, and counting problems where different positions create different outcomes.

Enter the total number of items as n and the number of selected items as r. The calculator will determine how many unique ordered arrangements are possible. It is especially helpful for students learning combinatorics and for anyone solving exam-style math questions.
